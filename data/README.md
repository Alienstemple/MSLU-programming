# Данные для практических занятий

Все файлы  простой текст в кодировке **UTF-8**. Ничего скачивать из интернета не нужно:
корпус маленький специально, чтобы всё считалось мгновенно и работало без сети.

| Файл | Что это | Где используется |
|---|---|---|
| `text_clean.txt` | аккуратный связный текст про язык и письменность | занятия 5, 6, 7, 13, 20, 21, 22 |
| `text_dirty.txt` | тот же жанр в «грязном» виде: лишние пробелы, разный регистр, HTML-мусор, дефисы, разные кавычки и тире | занятие 5 |
| `dialog.txt` | реплики диалога с именами говорящих | занятия 4, 5 |
| `words_ru.txt` | ~790 русских слов из этих текстов, по одному в строке, по алфавиту | занятия 6, 7, 13, 19, 22, 25, 29 |
| `stopwords_ru.txt` | список русских стоп-слов | занятия 7, 13, 29 |
| `synonyms.json` | небольшой тезаурус: 95 слов и 101 связь «близко по смыслу», один связный граф | занятие 24, обход графа |
| `corpus/doc01.txt` … `doc10.txt` | 10 коротких документов на разные темы | занятия 7, 9, 13, 22, 29 |
| `corpus_labels.json` | тематическая разметка корпуса: 10 документов, 4 категории | занятие 28 |
| `frequencies.csv` | таблица «слово, частота» по всем текстам, отсортирована по убыванию | занятия 5, 6, 19, 21 |

Файлы `words_ru.txt` и `frequencies.csv` получены из остальных текстов этой папки.
Их можно пересобрать в любой момент.

## Про `synonyms.json`

Это не словарь синонимов в строгом смысле. Связи означают близость по смыслу.
Часть из них настоящие синонимы («ошибка», «оплошность»), часть смежные понятия
(«справочник», «документ»). Так устроены и настоящие тезаурусы вроде WordNet.

Граф специально сделан **связным**: между любыми двумя словами существует путь.
Иначе на занятии 13 нечего было бы искать. Диаметр графа равен 26 шагам,
самая длинная цепочка идёт от «иллюстрация» до «мелодика».

Формат  список смежности: ключ это слово, значение это отсортированный список
соседей. Связи двусторонние: если `а` есть в списке `б`, то и `б` есть в списке `а`.

## Как открыть эти файлы

**В Colab:** загрузите папку `data` на Google Диск и подключите диск (см.
`setup/00_Colab_быстрый_старт.md`), либо загрузите файлы прямо в сессию через панель «Файлы» слева.

**Локально:** держите папку `data` рядом с папкой `notebooks`, и относительные пути
вида `../data/text_clean.txt` будут работать.

Во всех ноутбуках путь к данным задаётся один раз в самой первой ячейке.
При проблемах с путями менять нужно только её.

Номера занятий в таблице относятся к курсу Б1.В.4. Соответствие для Б1.В.2
смотрите в таблице программы `Основы_современного_программирования.md`.
