## 2. Что студент умеет в конце курса


- Знать синтаксис Python и общие принципы языков высокого уровня
- Декомпозировать задачу, превращать формулировку в набор шагов решения
- Выбирать структуру данных под задачу и обосновывать выбор ценой операции
- Узнавать основные классы алгоритмических задач и решать их: множества
  и словари, бинарный поиск, сортировки, префиксные суммы, скользящее окно,
  два указателя, интервалы, деревья, графы
- Читать код и находить в нём ошибки
- Собрать конвейер обработки текста и объяснить, что он теряет

Инструкции для настройки локальной среды лежат в папке `setup/`.

## 4. Что где лежит


```
theory/                      теория к каждому занятию
books/                       учебники курса + карта глав (books/README.md)
leetcode/                    подборка задач по занятиям
notebooks/                   ноутбуки (работают и в Colab, и локально)
notebooks/solutions/         решения домашних задач
data/                        тексты для практики, ничего скачивать не нужно
setup/                       инструкции по настройке: Colab, Python, Git
agent/                       памятка по агентской разработке (спеки, AGENTS.md)
exam/                        вопросы к экзамену, комплектование билетов
projects/                    темы итоговых проектов + критерии оценивания
```

## 5. Домашние задания: два трека

Основную работу делаем в классе. Дома - два трека, обязателен только первый.

**Минимум, обязательно, 20–30 минут, идёт в оценку.**
Несколько задач по теме занятия

**Трек «алгоритмы», по желанию, 1–1,5 часа, на оценку не влияет.**
Три-пять задач LeetCode по теме занятия, если есть желание готовиться к собеседованиям и стажировкам в ИТ.
