## 2. Что студент умеет в конце курса

- Знать синтаксис python и общие принципы ЯПВУ
- Декомпозировать задачи - превратить формулировку в набор шагов решения
- Выбирать структуры данных для алгоритмических задач и обосновать выбор
- Читать код и находить в нем ошибки
- Реализовать прикладную задачу обработки естественного языка
- Понимать, как устроены поисковые системы и языковые модели
- Знать основы агентной разработки ПО

## 3. Инструменты

Первая половина курса - в браузере, вторая - на своём компьютере.

| Среда | Б1.В.2 | Б1.В.4 |
| --- | --- | --- |
| **Google Colab** в браузере (не нужна локальная установка) | зан. 1–10 | зан. 1–24 |
| **Локально**: Python + VS Code + Jupyter + Git + GigaCode | зан. 11–15 | зан. 25–36 |
| **GigaCode CLI / плагин в IDE** | зан. 12–15 и проект | зан. 25–36 и проект |

Инструкции для настройки локальной среды - в папке `setup/`.

## 4. Что где лежит

```
theory/                      теория 
books/                       книги к курсу
notebooks/                   ноутбуки (работают и в Colab, и локально)
notebooks/solutions/         решения домашних задач
data/                        тексты для практики, ничего скачивать не нужно
setup/                       инструкции по настройке: Colab, Python, Git, GigaCode
agent/                       памятка по агентской разработке (спеки, AGENTS.md)
exam/                        вопросы к экзамену, комплектование билетов
projects/                    темы итоговых проектов + критерии оценивания
```
