# Диагностика ошибок

Справочник: найти симптом — выполнить указанные действия.

## Порядок действий при любой ошибке

1. Прочитать сообщение целиком. **Последняя строка** содержит тип ошибки и её суть.
2. Посмотреть номер строки. Ошибка часто находится строкой выше указанной.
3. Менять по одному изменению за раз.
4. Текст ошибки — рабочий поисковый запрос и корректный запрос к агенту.
5. Порядок перезапусков: ядро ноутбука → терминал → редактор.

## 1. Ошибки Python

### `SyntaxError: invalid syntax`
Интерпретатор не разобрал конструкцию. Обычные причины: пропущено двоеточие в конце `if`,
`for`, `def`; незакрытая скобка или кавычка. Проверять строку **выше** указанной: незакрытая
скобка обнаруживается на следующей строке.

### `IndentationError` / `unexpected indent`
Нарушены отступы; частая причина — смешение пробелов и табуляции.
VS Code: нижняя панель → «Spaces/Tab» → *Convert Indentation to Spaces*.

### `NameError: name 'x' is not defined`
Имя не определено к моменту использования:
- опечатка (`tekst` вместо `text`);
- в ноутбуке не выполнена ячейка выше, где создаётся переменная;
- переменная создана внутри функции и используется снаружи.

### `TypeError: can only concatenate str (not "int") to str`
Сложение строки и числа: `"Всего: " + 5`.
Решение: `"Всего: " + str(5)` или `f"Всего: {5}"`.

### `IndexError: list index out of range`
Индекс за границами: в списке из 3 элементов индексы 0, 1, 2.
Типичная причина: `for i in range(len(x) + 1)`.

### `KeyError: 'слово'`
Ключа нет в словаре. Проверить регистр и пробелы (`'Слово'` ≠ `'слово'` ≠ `'слово '`).
Безопасный доступ: `d.get('слово', 0)`.

### `ValueError: invalid literal for int() with base 10: 'abc'`
`int()` получил не число. Посмотреть фактический вход: `print(repr(x))`.

### `AttributeError: 'list' object has no attribute 'lower'`
Метод вызван у объекта другого типа. Проверить: `print(type(x))`.

### `ZeroDivisionError`
Деление на ноль, обычно `len(x)` пустой коллекции. Проверять длину до деления.

### `ModuleNotFoundError: No module named 'nltk'`
Библиотека не установлена в используемое окружение.
- Colab: `!pip install nltk`.
- Локально: убедиться, что в терминале `(.venv)`, затем `pip install nltk`.
- VS Code: `Ctrl/Cmd+Shift+P` → `Python: Select Interpreter` → `.venv`.

### `FileNotFoundError: [Errno 2] No such file or directory: 'data/text.txt'`
Диагностика:

```python
import os
print(os.getcwd())
print(os.listdir())
```

Далее исправить путь или переместить файл.

### `UnicodeDecodeError`
Файл не в UTF-8, обычно Windows-1251:

```python
open('файл.txt', encoding='cp1251')
```

Иначе: открыть файл в VS Code, кодировка внизу справа → *Save with Encoding* → UTF-8.

## 2. Colab

| Симптом | Решение |
|---|---|
| Переменная не определена, хотя ячейка выполнялась | сессия отключилась. `Среда выполнения → Перезапустить и выполнить всё` |
| Ячейка не завершается | вероятен бесконечный цикл. `Прервать выполнение`, проверить условие `while` |
| Загруженные файлы исчезли | сессионное хранилище очищено. Подключить Google Диск (`00_Colab_быстрый_старт.md`) |
| Поведение не соответствует коду | ячейки выполнялись не по порядку. `Перезапустить среду и выполнить всё` |
| «Превышен лимит использования» | подождать или использовать другой аккаунт |

## 3. Локальная среда

| Симптом | Решение |
|---|---|
| `python не является внутренней или внешней командой` | переустановить Python с галочкой «Add python.exe to PATH» |
| В терминале нет `(.venv)` | `.venv\Scripts\activate` (Windows) / `source .venv/bin/activate` (macOS) |
| Windows: «выполнение сценариев отключено» | `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`, подтвердить `Y` |
| Библиотека установлена, но не импортируется | установка и запуск в разных окружениях. `Python: Select Interpreter` → `.venv` |
| Ноутбук в VS Code не запускается | `Select Kernel` → Python Environments → `.venv` |
| Окружение повреждено | удалить `.venv` и создать заново (шаг 5 в `01_Python_и_VSCode.md`) |

## 4. Git

| Симптом | Решение |
|---|---|
| `fatal: not a git repository` | не та папка либо не выполнен `git init` |
| `Author identity unknown` | `git config --global user.name "..."` и `user.email "..."` |
| Пароль не подходит при `push` | нужен токен доступа из настроек GitHub/GitVerse |
| Закоммичен `.venv` | добавить `.venv/` в `.gitignore`, затем `git rm -r --cached .venv` и коммит |
| Вернуть файлы к последнему коммиту | `git restore имя_файла` или `git restore .` ⚠️ несохранённое удаляется |
| Открылся полноэкранный редактор | это `vim`: `Esc`, затем `:wq`, `Enter`. Сменить: `git config --global core.editor "code --wait"` |

## 5. GigaCode

| Симптом | Решение |
|---|---|
| `gigacode: command not found` | перезапустить терминал; проверить `npm -v`; переустановить `npm i -g @sber/gigacode-cli` |
| `401 Unauthorized` | `gigacode auth logout`, затем `login` |
| Плагин не даёт подсказок | проверить авторизацию, открыть файл `.py` |
| Агент не видит файлы проекта | `cd` в папку проекта, запустить заново |
| Агент изменил лишнее | `git restore .` |
| Агент ссылается на несуществующую функцию | штатное поведение модели. Проверять запуском кода. См. занятие 17 |

## Форма запроса о помощи

1. **Задача:** посчитать частоты слов в `text_clean.txt`.
2. **Действия:** запущена ячейка 5 в ноутбуке 06.
3. **Ожидаемый результат:** словарь «слово — частота».
4. **Фактический результат:** `FileNotFoundError: 'data/text_clean.txt'` (полный текст ошибки).

Формулировка работает одинаково для преподавателя, однокурсника, ИИ-ассистента и поиска.
