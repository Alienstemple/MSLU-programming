# GigaCode: плагин для VS Code и JetBrains


> ⚠️ Названия пунктов интерфейса могут отличаться от описанных.
> Источник истины — **https://gitverse.ru/features/gigacode/install/**.

## Плагин и CLI

| Возможность | Плагин | CLI |
|---|---|---|
| Подсказки кода при наборе | ✅ | ❌ |
| Объяснить выделенный фрагмент | ✅ | ✅ |
| Изменить несколько файлов сразу | ограниченно | ✅ |
| Запустить код и исправить по ошибке | ❌ | ✅ |

Плагин — повседневная работа с кодом в редакторе, CLI — сборка и изменение проекта целиком.

## ‼️ Перед установкой

В Marketplace VS Code есть неофициальные расширения с похожими названиями. Официальный плагин
ставится **из файла**, скачанного с сайта GitVerse, а не поиском по магазину. Проверять издателя.

## VS Code

1. **https://gitverse.ru/features/gigacode/install/** → **Visual Studio Code** → скачать
   файл **`.vsix`**.
2. Панель **Extensions** (`Ctrl/Cmd + Shift + X`).
3. **«…»** в правом верхнем углу панели → **Install from VSIX…**
4. Указать скачанный файл.
5. Перезапустить VS Code.
6. В строке состояния — кнопка **Connect GigaCode**, авторизоваться через GitVerse.


## JetBrains (PyCharm, IntelliJ IDEA)

Версия IDE **2024.2 и новее**.

1. На той же странице скачать **zip-архив** для JetBrains. **Не распаковывать.**
2. `Settings / Preferences` (`Ctrl+Alt+S` / `Cmd+,`) → **Plugins**.
3. ⚙ → **Install Plugin from Disk…** → выбрать zip.
4. Перезапустить IDE.
5. **Account** в панели GigaCode → авторизация через GitVerse.


> В **GigaIDE** плагин предустановлен: достаточно авторизации. Также существуют версии для
> Jupyter Notebook и Android Studio.

## Проверка

1. Открыть файл `.py`.
2. Ввести строку комментария и нажать Enter:

```python
# функция, которая принимает текст и возвращает список слов в нижнем регистре
```

3. Через секунду появляется серая подсказка. `Tab` — принять, `Esc` — отклонить.

## Основные функции

**1. Автодополнение.** Серый текст-продолжение, `Tab` / `Esc`.
Требование курса: читать предложенный код до нажатия `Tab`.

**2. Объяснение кода.** Выделить фрагмент → контекстное меню или панель GigaCode →
**«Объяснить»** (*Explain*).

**3. Чат по проекту.** Боковая панель, вопросы про открытый файл: «что произойдёт на пустом
списке», «перепиши понятнее, не меняя поведение».

**4. Комментарий как задание.** Точность комментария определяет качество заготовки:

```python
# плохо:
# обработать текст

# хорошо:
# принять строку, разбить на слова по пробелам и знакам препинания,
# привести к нижнему регистру, выбросить слова короче 3 букв,
# вернуть список слов; на пустой строке вернуть пустой список
```


## Ограничения

- Плохо поставленная задача даёт правдоподобный неверный код.
- Синтаксическая корректность не означает правильности.
- Модель не знает ваших данных (кодировка, структура корпуса).
- Ответственность за код — на авторе проекта.

## Частые проблемы

| Симптом | Решение |
|---|---|
| Подсказки не появляются | проверить авторизацию (Account / Connect); открыть файл с расширением `.py` |
| `401` | выйти из плагина и авторизоваться заново |
| Плагин не ставится из VSIX | обновить VS Code |
| Подсказки мешают | отключить в настройках плагина, вызывать по горячей клавише |
