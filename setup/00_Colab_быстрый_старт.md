# Google Colab: быстрый старт

**К занятию 1.** Colab — Jupyter-ноутбук в браузере, вычисления идут на сервере Google.
Установка не требуется.

## Требования

- браузер;
- аккаунт Google (`accounts.google.com`);
- интернет.

## Шаг 1. Открыть Colab

1. **https://colab.research.google.com**
2. Войти в аккаунт Google.
3. **«Создать блокнот»** (*New notebook*).

*Проверка:* видна пустая ячейка с иконкой ▶ слева.

## Шаг 2. Первая ячейка

Ввести в ячейку и нажать `Shift + Enter`:

```python
print("Привет, МГЛУ")
```

Первый запуск — 10–20 секунд (выделяется виртуальная машина). Под ячейкой должно появиться
`Привет, МГЛУ`.

## Шаг 3. Устройство ноутбука

| Вид ячейки | Содержимое | Добавить |
|---|---|---|
| **Код** (Code) | Python, выполняется | кнопка `+ Код` |
| **Текст** (Text) | Markdown: заметки, заголовки, формулы | кнопка `+ Текст` |

| Клавиши | Действие |
|---|---|
| `Shift + Enter` | выполнить и перейти к следующей |
| `Ctrl/Cmd + Enter` | выполнить и остаться |
| `Ctrl/Cmd + M`, `B` | добавить ячейку ниже |
| `Ctrl/Cmd + M`, `D` `D` | удалить ячейку |
| `Ctrl/Cmd + S` | сохранить |

Ячейки выполняются в порядке запуска, а не в порядке расположения на странице. Число в
`[5]` слева — порядковый номер запуска. Привести состояние в соответствие с текстом:
**«Среда выполнения → Перезапустить среду и выполнить всё»**.

## Шаг 4. Открыть ноутбук занятия

**Из файла:** `Файл → Загрузить блокнот` (*File → Upload notebook*), перетащить `.ipynb`.

**С Google Диска:** загрузить папку курса на Диск, затем `Файл → Открыть блокнот → Google Диск`.

Перед началом работы: `Файл → Сохранить копию на Диске`. Иначе правки не сохранятся.

## Шаг 5. Доступ к файлам данных

С занятия 4 нужна папка `data/`.

**Сессионное хранилище** (на один сеанс): иконка папки 📁 слева → «Загрузить в сессионное
хранилище». Файлы удаляются вместе с сессией.

**Google Диск** (постоянно): загрузить `data` на Диск, затем в ноутбуке

```python
from google.colab import drive
drive.mount('/content/drive')
```

и подтвердить доступ. Путь: `/content/drive/MyDrive/...`.

Во всех ноутбуках курса путь к данным задан в первой ячейке — переменная `DATA`. Править
только её.

## Частые проблемы

| Симптом | Причина | Решение |
|---|---|---|
| `NameError: name 'x' is not defined` | ячейка с определением `x` не выполнена | выполнить ячейки сверху вниз |
| `FileNotFoundError` | файла нет по указанному пути | проверить панель 📁 и написание имени |
| Ячейка не завершается | бесконечный цикл или обрыв сети | «Среда выполнения → Прервать выполнение» |
| «Среда выполнения отключена» | простой более 90 минут | переподключиться, выполнить ячейки заново; переменные потеряны |
| Непредсказуемое поведение | ячейки выполнялись не по порядку | «Перезапустить среду и выполнить всё» |

## Ограничения

- Требуется интернет.
- Сессия живёт несколько часов, файлы сессионного хранилища не сохраняются.
- Нет полноценной среды разработки: отладчик, работа с несколькими файлами, git.
