# ПК2. Предобработка корпуса

Напишите короткую программу на Python, которая решает задачу вашего варианта.

## Общие требования (для всех вариантов)

- Программа не длиннее **20 строк кода**. 
- Используется библиотека `nltk`. Нужные ресурсы скачиваются в начале программы через `nltk.download(...)` (список есть в подсказке).
- Результаты выводятся в консоль **с подписями**, например: `print("Слов в тексте:", len(words))`.
- Программа выкладывается в **репозиторий GitHub**.
- Нужно **уметь объяснить** работу программы.

## Вариант 1. Стоп-слова и частотный словарь

Корпус: `gutenberg`, файл `austen-persuasion.txt`.

1. Оставьте только слова (`isalpha()`) и приведите их к нижнему регистру.
2. Удалите стоп-слова (`stopwords.words("english")`).
3. Выведите число слов до и после удаления стоп-слов и 10 самых частых слов (`FreqDist`).

**Подсказка:** `from nltk.corpus import gutenberg, stopwords`, `from nltk import FreqDist`; метод `.most_common(10)`. Ресурсы: `gutenberg`, `stopwords`.

**Пример вывода:**
```
Слов до удаления стоп-слов: 84121
Слов после удаления: 38337
10 самых частых слов: [('anne', 497), ('could', 451), ('would', 355), ...]
```

## Вариант 11. Именные группы

Корпус: `gutenberg`, файл `chesterton-brown.txt`, предложения с 3-го по 7-е (`gutenberg.sents(...)[3:8]`).

1. Создайте парсер с готовой грамматикой: `RegexpParser("NP: {<DT>?<JJ>*<NN.*>+}")` (необязательный артикль, прилагательные, существительные).
2. Для каждого предложения выполните `pos_tag` и разберите его парсером.
3. Выведите все найденные именные группы (NP), каждую на отдельной строке.

**Подсказка:** `from nltk import pos_tag, RegexpParser`. Обойти найденные группы:
```python
for subtree in tree.subtrees(filter=lambda t: t.label() == "NP"):
    print(" ".join(word for word, tag in subtree.leaves()))
```
Ресурсы: `gutenberg`, `averaged_perceptron_tagger_eng`.

**Пример вывода:**

## Вариант 12. Именованные сущности

Корпус: `inaugural`, файл `2009-Obama.txt`, первые 50 предложений (`inaugural.sents(...)[:50]`).

1. Для каждого предложения выполните `pos_tag`, а затем `ne_chunk`.
2. Найдите в результате сущности: это элементы, у которых есть метка (`hasattr(subtree, "label")`).
3. Выведите каждую сущность в виде «тип - текст».

**Подсказка:** `from nltk import pos_tag, ne_chunk`. Обойти сущности:
```python
for subtree in tree:
    if hasattr(subtree, "label"):
        print(subtree.label(), "-", " ".join(word for word, tag in subtree.leaves()))
```
Ресурсы: `inaugural`, `averaged_perceptron_tagger_eng`, `maxent_ne_chunker_tab`, `words`.

**Пример вывода:**
```
PERSON - Bush
GPE - America
GPE - Gettysburg
LOCATION - Earth
...
```
