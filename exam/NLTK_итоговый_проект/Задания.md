# Итоговый проект

Напишите программу на Python, которая решает задачу вашего варианта.

## Общие требования (для всех вариантов)

- Программа на Python не длиннее **80 строк** (без учёта пустых строк и комментариев) с использованием библиотеки `nltk`.
- Ресурсы NLTK загружаются в коде через `nltk.download(...)`.
- Код разбит минимум на **3 функции**, у каждой есть короткий docstring.
- Результаты выводятся в консоль в читаемом виде: подписи, выравнивание.
- В конце программы в комментарии 2–3 предложения с выводом по результатам.
- Программа сдаётся в **репозитории GitHub**.
- Для защиты итогового проекта нужно **уметь объяснить**, как работает ваша программа, построчно.

## Вариант 1. Частотный и коллокационный анализ художественного текста

Корпус: `gutenberg`, файл `austen-emma.txt`.

1. Токенизировать текст и привести токены к нижнему регистру.
2. Удалить знаки препинания и стоп-слова (`stopwords`), лемматизировать слова с помощью `WordNetLemmatizer`.
3. Вывести 20 самых частых лемм с частотами (`FreqDist`) и лексическое разнообразие текста (число уникальных лемм / общее число лемм).
4. С помощью `BigramCollocationFinder` найти 10 лучших биграмм по мере PMI, отбросив биграммы с частотой меньше 5.

## Вариант 2. Сравнение частей речи в разных жанрах

Корпус: `brown`, категории `news` и `romance` (разметка `tagset='universal'`).

1. Для каждой категории получить размеченные слова и привести их к нижнему регистру.
2. Посчитать долю (%) тегов `NOUN`, `VERB`, `ADJ`, `ADV` в каждой категории.
3. Вывести сравнительную таблицу долей по двум жанрам.
4. Для каждого жанра вывести 10 самых частых прилагательных (`ADJ`), исключив стоп-слова.

## Вариант 3. Сравнение стеммеров и лемматизатора

Корпус: `gutenberg`, файл `carroll-alice.txt`.

1. Токенизировать текст, оставить только буквенные токены в нижнем регистре.
2. Обработать слова тремя способами: `PorterStemmer`, `LancasterStemmer`, `WordNetLemmatizer`. Лемматизатору передавать часть речи, полученную через `pos_tag`.
3. Для каждого способа вывести размер словаря (число уникальных форм) и процент его сокращения относительно исходного словаря.
4. Вывести таблицу из 15 слов, у которых результаты трёх методов различаются: исходное слово | Porter | Lancaster | лемма.

## Вариант 4. Семантические отношения в WordNet

Данные: список из 8 существительных, который задаётся в программе: `car, bicycle, dog, cat, apple, banana, teacher, doctor`.

1. Для каждого слова вывести число синсетов, определение первого синсета и до 5 синонимов (лемм).
2. Для каждого слова вывести цепочку гиперонимов первого синсета до корня (`hypernym_paths`).
3. Построить матрицу попарной близости слов по `path_similarity` (первые синсеты) и вывести её в виде таблицы.
4. Найти и вывести самую близкую и самую далёкую пары слов.

## Вариант 5. Классификатор пола по имени

Корпус: `names` (файлы `male.txt`, `female.txt`).

1. Сформировать размеченный набор `(имя, пол)` и перемешать его с фиксированным `random.seed`.
2. Написать функцию извлечения признаков: последняя буква, последние две буквы, длина имени, первая буква.
3. Разделить данные 80/20, обучить `NaiveBayesClassifier`, вывести accuracy и 10 самых информативных признаков.
4. Вывести 10 ошибок классификатора на тестовой выборке и предсказания для 5 имён, которые вводит пользователь.

## Вариант 6. Извлечение именных групп и именованных сущностей

Корпус: `gutenberg`, файл `chesterton-thursday.txt` (первые 300 предложений).

1. Разбить текст на предложения и токены, выполнить `pos_tag`.
2. Написать грамматику для `RegexpParser`, которая выделяет именные группы (NP): необязательный артикль, прилагательные, существительные. Вывести 15 самых частых NP.
3. Выполнить `ne_chunk` и посчитать количество сущностей каждого типа (`PERSON`, `GPE`, `ORGANIZATION` и др.).
4. Вывести по 5 самых частых сущностей каждого типа.
