## 1. Список

Упорядоченная изменяемая коллекция с повторами.

```python
items = ["a", "b", "c"]

items[0]           # 'a'
items[-1]          # 'c'
items[0:2]         # ['a', 'b']
len(items)

items.append("d")      # в конец
items.insert(0, "z")   # в начало
items.remove("b")      # по значению, первое вхождение
last = items.pop()     # снять с конца
items.index("c")       # позиция
"a" in items           # проверка наличия
```

### `sort` против `sorted`

```python
items.sort()             # на месте, возвращает None
result = sorted(items)   # копия, исходный цел
```

`items = items.sort()` уничтожает данные: список отсортирован на месте,
а имя связывается с `None`.

Правило сортировки задаётся параметром `key`:

```python
sorted(pairs, key=lambda p: p[1])                # по второму элементу
sorted(pairs, key=lambda p: p[1], reverse=True)  # по убыванию
sorted(words, key=len)                           # по длине
sorted(pairs, key=lambda p: (len(p[0]), -p[1]))  # два критерия сразу
```

Кортеж в `key` означает сортировку по нескольким критериям: сначала по первому,
при равенстве по второму. Минус перед числом переворачивает направление
для одного критерия.

### Включения

```python
long_words = [w for w in words if len(w) > 4]
lengths = [len(w) for w in words]
```

Включение должно помещаться в строку и читаться вслух. Двухэтажная конструкция
с тремя условиями пишется обычным циклом.

## 2. Список это ссылка

```python
a = ["x", "y"]
b = a                # второе имя для того же объекта
b.append("z")
print(a)             # ['x', 'y', 'z']
```

Присваивание не копирует. Копия делается явно:

```python
b = a.copy()         # или a[:], или list(a)
```

Это одна из немногих ошибок курса, которая портит данные без всякого сообщения.

## 3. Кортеж

Неизменяемая последовательность.

```python
point = (55.75, 37.62)
record = ("Pushkin", 1799, "poet")
name, year, role = record        # распаковка
```

Практическое различие в смысле:

| Список | Кортеж |
|---|---|
| много однотипных вещей | одна вещь из разных по смыслу частей |
| длина меняется | длина фиксирована |
| элементы взаимозаменяемы | у каждой позиции своя роль |

Кортеж может быть ключом словаря, список не может (занятие 7).
Функция, возвращающая несколько значений, возвращает кортеж:

```python
def stats(text):
    words = text.split()
    return len(words), len(set(words))

total, unique = stats(text)
```

## 4. Как это лежит в памяти

**Массив.** Элементы подряд. Адрес i-го элемента вычисляется арифметически,
поэтому доступ по индексу мгновенный. Вставка в середину сдвигает всё правее.

**Связный список.** Элементы вразброс, каждый хранит ссылку на следующий.
Вставка дешёвая, доступ по индексу требует прохода от начала.

| Операция | Массив | Связный список |
|---|---|---|
| взять i-й | O(1) | O(n) |
| вставить в середину | O(n) | O(1) |
| вставить в конец | O(1) | O(1) |

`list` в Python это массив. Отсюда всё поведение из раздела 1: индекс дёшев,
`append` дёшев, `insert(0, x)` дорог. Связные списки разбираются на занятии 24.

## 5. Цена операции

Скорость измеряют не в секундах, они зависят от машины. Измеряют ростом работы
при росте данных: если n вырастет в 10 раз, во сколько раз вырастет работа?

| Запись | Рост при n × 10 | Пример |
|---|---|---|
| O(1) | не меняется | `d[key]`, `len(x)`, `x[5]` |
| O(log n) | плюс несколько шагов | бинарный поиск |
| O(n) | в 10 раз | проход по списку, `x in list` |
| O(n log n) | чуть больше 10 раз | сортировка |
| O(n²) | в 100 раз | вложенный цикл по одним данным |

Если одна операция занимает микросекунду:

| n | O(n) | O(n log n) | O(n²) |
|---|---|---|---|
| 1 000 | 0,001 с | 0,01 с | 1 с |
| 100 000 | 0,1 с | 1,7 с | 3 часа |
| 1 000 000 | 1 с | 20 с | 11 дней |

Правила чтения:

* константы отбрасываются, `3n + 100` это O(n),
* берётся старший член, `n² + n` это O(n²),
* вложенный цикл по одним данным даёт умножение,
* два цикла подряд дают сложение, то есть остаются O(n).

O-нотация описывает худший случай и скорость роста. Алгоритм O(n²) на 20 элементах
быстрее, чем O(n log n) на миллионе. Вопрос всегда в том, какие у вас данные.

### Цена операций в Python

| Операция | `list` | `set` и `dict` |
|---|---|---|
| `x in c` | O(n) | O(1) |
| доступ по индексу | O(1) | нет |
| доступ по ключу | нет | O(1) |
| добавление в конец | O(1) | O(1) |
| вставка в начало | O(n) | нет |
| удаление по значению | O(n) | O(1) |
| сортировка | O(n log n) | нет |

Три вывода:

1. `in` по списку линеен, по множеству мгновенен. Много проверок, стройте множество.
2. `insert(0, x)` в цикле даёт скрытый квадрат. Добавляйте в конец, потом разверните.
3. Сортировка недорога. Опасно сортировать внутри цикла.

## 6. Как увидеть квадрат

Три признака.

```python
# 1. цикл в цикле по одним данным
for a in items:
    for b in items:
        ...

# 2. `in` по списку внутри цикла, второй цикл спрятан внутри `in`
for word in words:
    if word in other_list:
        ...

# 3. коллекция пересобирается на каждом шаге
for word in words:
    seen = set(processed)
    ...
```

Третий случай коварнее прочих. Он выглядит как забота о корректности,
а множество строится заново на каждой итерации. Стройте до цикла.

## 7. Частые ошибки

**`items = items.sort()`.** Данные уничтожены.

**`b = a` вместо `b = a.copy()`.** Два имени одного списка.

**`x in list` внутри цикла.** Скрытый квадрат.

**Пересборка `set()` внутри цикла.** То же самое.

**`insert(0, x)` в цикле.** O(n²) на ровном месте.

**Изменение списка во время обхода.** Элементы пропускаются.

**Вывод «работает, значит нормально».** Работает на ваших ста элементах.
