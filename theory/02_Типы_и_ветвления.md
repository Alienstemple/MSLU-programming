## 1. Тип принадлежит значению

В Python тип связан со значением, а имя переменной типа не имеет. Одно и то же имя
может в разные моменты указывать на значения разных типов.

```python
value = 42        # int
value = "42"      # str, то же имя
value = [42]      # list
```

Это называется динамической типизацией. Объявлять типы не нужно, плата за удобство:
часть ошибок обнаруживается только при запуске той строки, где они допущены.

Пять базовых типов:

| Тип | Что хранит | Литерал |
|---|---|---|
| `int` | целое число произвольной величины | `42`, `-7`, `10**100` |
| `float` | число с плавающей точкой | `3.14`, `1e-9` |
| `str` | строка символов | `"text"`, `'text'` |
| `bool` | истина или ложь | `True`, `False` |
| `NoneType` | отсутствие значения | `None` |

`int` в Python не ограничен размером машинного слова. `2 ** 1000` вычисляется точно.

## 2. Преобразования

### Неявное расширение

Числовые типы расширяются автоматически в сторону более общего.

```python
7 + 3.0      # 10.0, int расширился до float
True + 1     # 2, bool это подкласс int
```

Строка в этой цепочке не участвует. `"5" + 5` даёт `TypeError`, потому что `+`
для строки означает склейку, для числа сложение, и выбрать за вас Python отказывается.

### Явное преобразование

```python
int("2026")     # 2026
int(3.99)       # 3, дробная часть отбрасывается без округления
float("3.14")   # 3.14
str(42)         # "42"
```

`int()` от строки требует, чтобы строка целиком была записью числа. Пробелы по краям
допускаются, всё остальное даёт `ValueError`.

```python
int(" 42 ")     # 42
int("42.0")     # ValueError
int("сорок")    # ValueError
```

Отсюда правило для данных, пришедших извне: перед преобразованием проверяйте
или ловите исключение (занятие 5).

### Точность float

```python
0.1 + 0.2 == 0.3      # False
```

Двоичная дробь не представляет 0.1 точно, как десятичная не представляет 1/3.
Свойство стандарта IEEE 754, общее почти для всех языков.

Практические выводы:

* дробные числа не сравнивают на точное равенство, сравнивают модуль разности
  с малым порогом или пользуются `math.isclose`,
* деньги во `float` не хранят, берут целые копейки или `decimal.Decimal`.

## 3. Истинность значений

В логическом контексте любое значение приводится к `True` или `False`.
Ложны только «пустые» значения.

| Ложь | Истина |
|---|---|
| `False`, `None` | `True` |
| `0`, `0.0` | любое ненулевое число |
| `""` | непустая строка |
| `[]`, `{}`, `set()` | непустая коллекция |

```python
if items:            # так проверяют, что список непуст
    ...
if len(items) > 0:   # то же самое, длиннее
    ...
```

Осторожно с числом 0. Проверка `if count:` пропустит настоящий ноль,
и если ноль для вас осмысленное значение, пишите `if count is not None:`.

## 4. Сравнения и логика

```python
a == b     # равенство значений
a != b     # неравенство
a < b      # строгое меньше
a <= b     # меньше или равно
```

Цепочки сравнений работают как в математике и вычисляются один раз:

```python
0 <= index < len(items)
```

### `==` против `is`

`==` сравнивает значения, `is` сравнивает тождество объектов.

```python
a = [1, 2]
b = [1, 2]
a == b     # True, содержимое одинаково
a is b     # False, это два разных объекта
```

`is` применяют к `None`, `True`, `False` и больше почти ни к чему.
Пишут `if value is None`, не `if value == None`.

### Логические операторы

`and`, `or`, `not`. Оба бинарных оператора вычисляются с коротким замыканием:
правый операнд не вычисляется, если результат уже ясен по левому.

```python
if index < len(items) and items[index] > 0:
    ...
```

Порядок здесь существенный. При пустом списке левая проверка даёт `False`,
и обращения к `items[index]` не происходит. Поменяйте местами, получите `IndexError`.

Сложное условие стоит назвать:

```python
is_valid = 0 < value < 100 and value % 2 == 0
if is_valid:
    ...
```

## 5. Ветвление

```python
if score >= 90:
    grade = "A"
elif score >= 75:
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "F"
```

Ветки проверяются сверху вниз, выполняется первая подошедшая.
Блок задаётся отступом, обычно четыре пробела.

### Порядок проверок

Классическая ошибка, которая не даёт сообщения:

```python
if score >= 60:
    grade = "C"
elif score >= 90:      # недостижимо
    grade = "A"
```

Всё, что больше 90, уже больше 60, поэтому вторая ветка не выполнится никогда.
Программа работает и выдаёт неправильный результат. Проверять надо
от частного к общему.

### Условное выражение

Для выбора одного из двух значений есть короткая форма:

```python
label = "even" if n % 2 == 0 else "odd"
```

Пользуйтесь ей, когда выражение помещается в строку и читается вслух.

## 6. Частые ошибки

**`=` вместо `==` в условии.**
`if x = 5:` даёт `SyntaxError`. В этом Python удобнее C, где такая опечатка
компилируется и портит данные.

**Сравнение float на равенство.**
`0.1 + 0.2 == 0.3` ложно. Сравнивайте с порогом.

**`if value == None`.**
Работает, но пишут `is None`.

**Порядок проверок от общего к частному.**
Ветка становится недостижимой, сообщения об ошибке нет.

**Забытое преобразование после `input`.**
`input()` возвращает строку всегда. `"5" + 5` это `TypeError`,
а `"5" * 3` это `"555"`, что гораздо неприятнее: ошибки нет, результат неверен.

**`if count:` для числа, где ноль осмыслен.**
Ноль ложен, ветка молча пропускается.
