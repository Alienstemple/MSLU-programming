## 1. Индексы и срезы

Строка это последовательность символов. Индексация с нуля, отрицательные индексы
отсчитываются с конца.

```
 p  y  t  h  o  n
 0  1  2  3  4  5
-6 -5 -4 -3 -2 -1
```

```python
word = "python"

word[0]      # 'p'
word[-1]     # 'n'
len(word)    # 6
word[6]      # IndexError
```

Срез `[start:stop:step]` возвращает новую строку. Правая граница не включается.

```python
word[0:3]     # 'pyt'
word[:3]      # то же, начало можно опустить
word[3:]      # 'hon'
word[-2:]     # 'on'
word[::2]     # 'pto'
word[::-1]    # 'nohtyp'
```

Длина среза равна `stop - start`. Срез не выходит за границы и не даёт исключения:

```python
"abcd"[0:100]    # 'abcd'
"abcd"[10:20]    # ''
```

Удобно, и в этом же ловушка. Опечатка в границах никак себя не проявит,
срез тихо вернёт не тот кусок.

## 2. Неизменяемость

Строку изменить нельзя, можно только построить новую.

```python
word = "python"
word[0] = "P"          # TypeError
word = "P" + word[1:]  # так
```

Следствие первое: строка может быть ключом словаря (занятие 7).
Хеш вычисляется один раз и не устаревает.

Следствие второе, практическое. Каждое `+` создаёт новую строку целиком,
поэтому склейка в цикле квадратична:

```python
result = ""
for word in words:          # 100 000 слов
    result = result + word  # на каждом шаге копируется всё накопленное

result = "".join(words)     # один проход
```

Копите в списке, склеивайте один раз через `join`.

## 3. Методы

Методы возвращают новую строку и не меняют исходную.

| Метод | Действие |
|---|---|
| `.lower()`, `.upper()` | регистр |
| `.strip()`, `.lstrip()`, `.rstrip()` | убрать пробельные символы по краям |
| `.replace(old, new)` | заменить все вхождения |
| `.startswith(s)`, `.endswith(s)` | проверка начала и конца |
| `.find(s)` | индекс первого вхождения или `-1` |
| `.index(s)` | то же, но `ValueError`, если нет |
| `.count(s)` | число вхождений |
| `.split(sep)`, `.join(items)` | разбиение и склейка |

Классическая ошибка: вызвать метод и не присвоить результат.

```python
text.strip()          # результат выброшен
text = text.strip()   # так
```

Проверки возвращают `bool`:

```python
"12".isdigit()      # True
"ab".isalpha()      # True
"ёж".isalpha()      # True, Юникод учитывается
"a-b".isalpha()     # False, дефис не буква
"  ".isspace()      # True
```

`isdigit` полезен перед `int()`, когда данные пришли извне.

## 4. `split` и `join`

```python
"a b c".split()          # ['a', 'b', 'c']
"a,b,c".split(",")       # ['a', 'b', 'c']
" ".join(["a", "b"])     # 'a b'
```

`join` записывается наоборот по сравнению с ожидаемым: разделитель впереди.
Читается как «соединить этот список, вставляя между элементами вот это».

Вызов без аргумента и вызов с пробелом ведут себя по-разному:

```python
"a  b".split()       # ['a', 'b'], подряд идущие пробелы схлопываются
"a  b".split(" ")    # ['a', '', 'b'], между двумя пробелами пустая строка
```

Первый вариант нужен почти всегда. Второй даёт пустые элементы,
которые потом всплывают в подсчётах.

Ограничение числа разбиений задаётся вторым аргументом:

```python
"key=value=extra".split("=", 1)     # ['key', 'value=extra']
```

## 5. Поиск подстроки

```python
"th" in "python"        # True
"python".find("th")     # 2
"python".find("xx")     # -1
```

Оператор `in` для строк реализован на C и работает быстро. Своих алгоритмов поиска
писать не нужно, пока задача не потребует много сравнений сразу (занятие 22).

Форматирование вывода разбиралось на занятии 1:

```python
print(f"{word:>12} {count:>5}")     # выравнивание в колонки
```

## 6. Частые ошибки

**Метод вызван, результат не присвоен.** `text.lower()` сам по себе ничего не меняет.

**Попытка присвоить по индексу.** `word[0] = "P"` даёт `TypeError`.

**Ожидание, что `[0:5]` даст шесть символов.** Правая граница не включается.

**`split()` и `split(" ")` считаются одинаковыми.** На подряд идущих пробелах
результат разный.

**Склейка строк в цикле.** Работает на сотне элементов, на сотне тысяч даёт минуты
вместо миллисекунд.

**`find` перепутан с `index`.** Первый возвращает `-1`, второй бросает исключение.
Проверка `if text.find(s):` ошибочна вдвойне: `-1` истинно, а найденное на нулевой
позиции `0` ложно.
