# Основы современного программирования

**МГЛУ, «Фундаментальная и прикладная лингвистика»**
**Б1.В.2, 1 курс, 2 семестр, 144 часа / 4 з.е., экзамен**

---

## 1. Карта курса

Один семестр, 18 занятий. Синтаксис с нуля, структуры данных, алгоритмические
приёмы, затем прикладной блок по обработке текста.

```
I.   Инженерное мышление и синтаксис      зан. 1–5     Colab
II.  Структуры данных                     зан. 6–7     Colab
     РЕЗЕРВ 1. Контроль №1                       зан. 8
III. Алгоритмические приёмы               зан. 9–13    Colab
     РЕЗЕРВ 2. Контроль №2, тема проекта      зан. 14
IV.  Обработка текста                     зан. 15–17   Colab
     РЕЗЕРВ 3. Защита проекта, экзамен           зан. 18
```

Курс целиком идёт в Google Colab, локальная установка не требуется.

## 3. Домашняя работа

**Минимум, обязательно, 20–30 минут, идёт в оценку.** Несколько задач по теме занятия

**Трек «алгоритмы», по желанию, на оценку не влияет.** Три-пять задач LeetCode
для тех, кто хочет готовиться к собеседованиям и стажировкам в ИТ
